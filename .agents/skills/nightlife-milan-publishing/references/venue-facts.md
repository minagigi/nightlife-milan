# Venue Facts

Always re-check the current event and Xceed source before publishing. These are product guardrails, not permission to invent a service for a specific night.

## Just Me Milano

- Priority venue.
- Core audience: international, normally 21+.
- Possible services: aperitivo, dinner, Thursday singing or show dinner, nightclub.
- Tables: dance floor, prive, and super-prive.

## Pineta Milano

- Priority venue.
- Core audience: international, normally 18+.
- Possible services: aperitivo, nightclub, and dinner show only when the individual night confirms it.
- Tables: dance floor, prive, and super-prive.

## Aria Club Milano

- Priority venue.
- Core audience: primarily Italian, normally 18+.
- Possible services: aperitivo and nightclub.
- Do not advertise dinner as an Aria service unless a current authoritative event source explicitly changes the product.
- Tables: dance floor, prive, and super-prive.

## Source Priority

1. Current official event or Xceed affiliate page.
2. Current Eventbrite record owned by Nightlife Milan.
3. Repository venue data and approved event templates.
4. Ask the user when authoritative sources conflict.

Prices and availability are always event-specific. Never reuse an old price without checking the current source and exact affiliate link.
